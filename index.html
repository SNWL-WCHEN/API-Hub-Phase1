MySonicWall (MSW) API Key

One key, generated once, works for NSM, SonicOS, and Capture Client — you exchange it for a short-lived token per product.

  1. Log in to mysonicwall.com → My Workspace → User Groups
  2. Click Generate My API Key (valid up to 1 year)
  3. Exchange it for a product token via POST /generate-cscaccesscode, then the product's own token endpoint

Cloud Secure Edge API Key

CSE runs on its own Command Center identity system — it does not use an MSW key.

  1. Log in to your Command Center
  2. Go to Settings → API Keys → Add API Key for automation, or My Profile for an interactive refresh token
  3. Use the key or token as a Bearer credential on CSE calls
